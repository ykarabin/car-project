# Задній привід

Стік газу задає швидкість, правий MT6826S дає зворотний зв'язок, один
PI-регулятор формує однаковий PWM для обох задніх двигунів. Незалежних
регуляторів коліс і електронного диференціала немає. Код —
`drive_controller.c`, параметри — `drive_controller_config.h`.

## Режими

Для ELRS режим задає трипозиційний CH3: нижче −500 — 1, від −500 до +500 — 2,
вище +500 — 3. Для PWM-приймача CH3 перемикає режими по колу (див.
[radio-setup.md](radio-setup.md)).

| Режим | Повний стік | Реалізація |
| --- | --- | --- |
| 1 | 4 км/год | завдання до ±1111 мм/с |
| 2 | 6 км/год | завдання до ±1666 мм/с |
| 3 | MAX | масштаб номіналу 2800 RPM (≈7,65 км/год); від \|стік\| ≥ 990 — повний PWM в обхід PI |

Ліміти однакові в обидва боки й рахуються за правим колесом: однаковий PWM
не гарантує однакових обертів коліс у повороті чи при ковзанні.
Нейтраль ±30 / 1000 (`VEHICLE_STICK_DEADBAND`) спільна для приводу, керма,
калібрування й очікування нейтралі.

## Регулятор

Вихід = feed-forward + P + I, цілочисельно, без heap і float.

| Параметр | Значення |
| --- | --- |
| Крок | 10 мс, фактичний elapsed; пауза ≥ 50 мс перезапускає з нульовим виходом |
| Kp | 100 ‰ PWM на м/с |
| Ki | 300 ‰ PWM на м/с·с; інтегратор у тисячних PWM |
| Feed-forward | 750 ‰ на номінальній швидкості |
| Наростання / звичайне спадання | 10 ‰ за 10 мс (повний діапазон за 1 с) |
| Гальмування й зміна напрямку | 20 ‰ за 10 мс (за 0,5 с) |

Anti-windup: інтеграл не накопичується, коли вихід упирається в межу PWM
або рампи в бік помилки. Інтегратор скидається в нейтралі, при реверсі,
тривалому збої feedback і калібруванні; зміна режиму його зберігає.
Якщо колесо швидше за завдання, регулятор зменшує PWM до 0, але протилежний
напрямок заради гальмування не вмикає. Записи CCR1/CCR2 виконуються під
TIM1 UDIS, тож обидва задні канали оновлюються одним update event.

## Реверс

Фази руху (`motion`): IDLE, RUNNING, REVERSING, REVERSE_SETTLE,
NEUTRAL_SETTLE. Дозвіл реверсу (`reverse_stage`) — окремий автомат:
BRAKE_REQUIRED → FORWARD_SEEN → WAIT_NEUTRAL → READY → ACTIVE.

- Перше «назад» під час руху або спадання PWM — гальмування (BRAKING):
  PWM до нуля з темпом 20 ‰. Утримання стіка назад реверс не вмикає.
- Нейтраль, потім друге «назад» — реверс після PWM = 0 і зупинки RIGHT
  (±50 мм/с протягом 100 мс).
- Другий шлях (з 19.11.2026): після фактичного руху вперед, нейтралі,
  PWM = 0 і тих самих 100 мс спокою перше ж «назад» дозволене.
- Після старту, тривалої помилки, паузи ≥ 50 мс або сервісу потрібна
  послідовність гальмо → нейтраль → назад; саме очікування дозволу не дає.
- Перехід назад → вперед теж спершу доводить PWM до нуля й чекає зупинки.

## Feedback і збої

RIGHT придатний, якщо стан OK, вік < 20 мс, вікно > 0 і < 50 мс,
\|швидкість\| ≤ 5000 мм/с. Обрив A/B ці перевірки окремо не виявляють:
він виглядає як свіжі нульові відліки.

| Подія | Задні двигуни |
| --- | --- |
| Збій RIGHT до 40 мс | FEEDBACK_HOLD: лише зменшення PWM, I не накопичується |
| Збій RIGHT від 40 мс | PWM = 0 (гальмо), дозвіл реверсу скинуто |
| Помилка пульта до 60 мс | остання перевірена OK-команда |
| Помилка пульта від 60 мс або вік OK ≥ 100 мс | SLP LOW (накат) |
| Калібрування (PC13 3 с) | обидва SLP LOW |

## Історія налаштування

У хронологічному порядку, 18–19.11.2026. Усі вимірювання — на піднятому
авто, без навантаження коліс.

| # | Зміна | Результат |
| --- | --- | --- |
| 1 | Перший PI: Kp 250, Ki 500, FF 1000 | режим 1 (завдання 3 км/год): пік 3,59 км/год, сталі 3,0 км/год при ~30 % PWM |
| 2 | Kp 100, Ki 300, FF 750 | сталі ≈ 3,0 / 5,0 км/год для завдань 3 / 5 |
| 3 | Час вимірювання енкодера з HAL tick → мікросекунди (TIM6) | сталі 3,00 / 4,98 км/год, піки 3,26 / 5,34; швидкі коливання показів лишились |
| 4 | Рампа PWM в обидва боки, I зберігається при зміні режиму | команда PWM змінюється плавно; оцінка ударів оператором не записана |
| 5 | Ліміти 3 / 5 → 4 / 6 км/год; спадання 10 ‰, гальмування 20 ‰ | нові ліміти на стенді не вимірювались |
| 6 | RC-реверс: гальмо → нейтраль → назад | оператор: «перший раз гальмує, другий — задній хід» |
| 7 | Допуск збоїв пульта 40 → 60 мс, feedback 40 мс | прибрано обриви PWM від одиничних NE-помилок UART |
| 8 | Реверс після зупинки в нейтралі | оператор: «обидві послідовності працюють» |

Не виміряно: фактичні 4 / 6 км/год після зміни лімітів, час і шлях зупинки,
поведінка під навантаженням. Пікові перевищення завдання ще треба зменшити.
