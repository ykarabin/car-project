# Керування електроавто з пульта

Проєкт на C для ESP32-S3 та STM32G473VET6. Gateway приймає команди
радіопульта, а ECU керує швидкістю заднього приводу й положенням керма
за зворотним зв'язком від енкодерів.

```text
Пульт → ELRS / PWM RC → ESP32-S3 → UART → STM32G473 → драйвери → двигуни
                                             ↑                  │
                                             └──── енкодери ────┘
```

## Функції

- ELRS/CRSF та альтернативний приймач із трьома PWM-каналами.
- Передавання команд UART кожні 20 мс, CRC-16, sequence та timeout.
- Спільний PI заднього приводу за правим енкодером; однаковий PWM
  обох задніх двигунів, режими 4 км/год, 6 км/год та MAX.
- P-регулятор керма; після відпускання стіка — повернення до центру,
  потім звільнення для ручного повороту.
- Плавні зміни PWM та послідовність дозволу заднього ходу.
- Калібрування трьох точок кнопкою PC13 із записом у Flash.
- Дві задачі FreeRTOS на STM32: керування та форматування/вивід RTT.
- Обробка помилок UART/feedback, FLT драйверів та IWDG.

## Структура

| Каталог | Призначення |
| --- | --- |
| `firmware/remote-gateway` | ESP32-S3, ESP-IDF: ELRS, PWM RC, вибір джерела, UART TX |
| `firmware/vehicle-ecu` | STM32: периферія, керування, FreeRTOS, калібрування, RTT |
| `shared/remote_protocol` | Спільні типи команд, форматування, CRC та парсер |
| `docs` | Архітектура, підключення та інструкція запуску |

HAL, CMSIS, FreeRTOS і SEGGER RTT включені до STM32-проєкту разом
із ліцензіями постачальників. Для Gateway потрібен встановлений ESP-IDF.

## Збірка

STM32: CMake 3.22 або новіший, Ninja та Arm GNU Toolchain з
`arm-none-eabi-gcc` у PATH. Перевірений компілятор — GCC 14.3.1.

```sh
cd firmware/vehicle-ecu
cmake --preset Debug
cmake --build --preset Debug
```

Результат: `build/Debug/vehicle-ecu.elf`. Для оптимізованої збірки
використати preset `Release`.

ESP32-S3: ESP-IDF 6.0.1 із встановленими інструментами для `esp32s3`.
Команди виконуються в активованому середовищі ESP-IDF:

```sh
cd firmware/remote-gateway
idf.py set-target esp32s3
idf.py build
```

Результат: `build/remote-gateway.elf` і файли для прошивання.
`sdkconfig.defaults` та Kconfig компонентів задають початкову конфігурацію.

## Особливості реалізації

Швидкість визначається правим енкодером; незалежне регулювання коліс
та електронний диференціал не реалізовані. Лівий енкодер і вимірювання
струму не використовуються. Налаштування цих виводів збережені в CubeMX.

Режими 4/6 км/год задають верхню межу швидкісного завдання PI-регулятора.
